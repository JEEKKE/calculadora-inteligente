# 🧮 Calculadora Inteligente

Uma calculadora desenvolvida em Python como parte dos meus estudos de programação, com foco na prática de lógica de programação, funções, estruturas de repetição e tratamento de erros.

O projeto permite realizar operações matemáticas básicas e consultar o histórico dos cálculos realizados durante a execução do programa.

## ✨ Funcionalidades

- ➕ Adição
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão
- 🔢 Suporte a números inteiros e decimais
- 🛡️ Tratamento de entradas numéricas inválidas
- ⚠️ Tratamento de divisão por zero
- 🔄 Menu interativo que permite realizar várias operações
- 📋 Histórico de operações com números utilizados e resultados
- 🚪 Opção para encerrar o programa

## 🛠️ Tecnologias utilizadas

- **Python 3** — desenvolvimento da aplicação
- **Git** — controle de versão
- **GitHub** — hospedagem e compartilhamento do código

## ▶️ Como executar

1. Instale o Python 3.
2. Clone este repositório ou baixe os arquivos do projeto.
3. Abra o terminal na pasta do projeto.
4. Execute o programa com o comando:

   `python3 main.py`
